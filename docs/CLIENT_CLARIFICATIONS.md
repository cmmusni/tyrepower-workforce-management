# Client Clarifications Needed

These are the key MVP clarifications required before finalizing scope and timeline.

## 1. App Delivery: Native App vs PWA (Most Important)

Question:
Do you want a native mobile app (downloaded from App Store / Google Play), or a web app that employees can install directly from the browser (PWA - Progressive Web App)?

| Capability | PWA (Browser-installable) | Native App (App Store) |
|------------|---------------------------|------------------------|
| Installation | Add to Home Screen from browser | Download from App Store / Play Store |
| Development time | Included in current plan | +10-14 weeks additional |
| Cost | $0 extra | +$150/yr Apple + $35 Google + build costs |
| Push notifications | Yes | Yes |
| GPS / Geofencing | Yes | Yes |
| QR scanning | Yes | Yes |
| Offline support | Yes (limited) | Yes (full) |
| Background GPS | No | Yes |
| Biometric login (Face ID) | No | Yes |

Current plan assumption:
PWA (no app store). If native is required, timeline and cost increase significantly.
